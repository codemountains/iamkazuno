# コンテンツ管理

[READMEに戻る](../README.md)

## 接続

1. microCMSの管理画面で、[公式手順](https://document.microcms.io/content-api/x-microcms-api-key)に従ってAPIキーを発行します。必要な権限は [.env.example](../.env.example) を参照してください。
2. ローカルでは `.env.example` から `.env` を作成し、接続情報を設定します。既存の `.env` があれば、そのファイルを編集してください。

## 更新

microCMSでコンテンツと必要な参照先を公開し、[公開手順](deployment.md)でサイトへ反映します。

商品登録・画像作成の手順は [既存スキル](../.agents/skills/) を参照してください。
